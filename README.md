# mpv_slim

MPV Slim 是一个精简但质量不低的 mpv 播放器配置。

## 特点

- 精简但质量不低 -> 只实现必要功能，选择质量最好的不冗余的算法
- 创作者意图优先 -> 尽可能还原创作者的意图，绝不搞花里胡哨的东西
- SOFA 空间音频 -> 顶级多声道下混，在耳机里体验多声道的环绕声
- 响度标准化 -> 防止不同视频音量忽高忽低
- EQ 均衡器 -> 支撑通用的 APO Eq 曲线，可以校准耳机响应曲线
- 完美色调映射 -> HDR 到 SDR 的完美亮度和色调映射
- KrigBilateral + RAVU + ArtCNN -> 顶级视频升频率算法，拒绝破坏创造者意图
- NLMeans 降噪 -> 提供独立开关的降噪功能，以应对垃圾视频
- alass -> 全自动同步不对齐的字幕

## 快捷键

| 按键 | 功能 |
|------|------|
| T | 字幕放大 +0.1 |
| t | 字幕缩小 -0.1 |
| j | 字幕位置 -1 |
| k | 字幕位置 +1 |
